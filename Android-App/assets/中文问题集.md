# MiniCPM-V 中文问题集

这组问题用于展示模型的文本推理、图像理解、结构化提取和日常辅助能力。

## 一、纯文本问题

### 1. 论文方法概括

请阅读下面这段论文摘要，用中文回答：这篇论文解决了什么问题？核心方法是什么？它相对于已有方法的主要改进是什么？请用“问题—方法—结果”三句话回答。

### 2. 实验结果分析

某模型在三个数据集上的准确率分别为 81.2%、84.7% 和 83.9%，基线模型分别为 78.5%、85.1% 和 80.4%。请计算每个数据集上的百分点变化，并判断该模型是否稳定优于基线。

### 3. 研究方案设计

我想研究“端侧多模态模型在低功耗设备上的响应延迟”。请设计一个可复现实验，至少说明：硬件、模型、输入样本、测量指标、重复次数和需要控制的变量。

### 4. 论文首页转 Markdown

请将提供的论文首页整理为 Markdown，保留论文标题、作者、机构、摘要和关键词；不要臆造图片中看不清的内容；无法确认的字段标记为“待确认”。

## 二、带图片问题

### 5. 科研图表阅读

请观察图片中的折线图，找出最低点对应的数值和日期，说明你是如何从横轴和纵轴读出的。如果图中使用的不是摄氏度，请指出原始单位并说明是否需要换算。

### 6. 拿破仑行军路线图

请观察 `minard-napoleon-march.png`，回答：图中黑色路线表示什么？军队人数大约从多少减少到多少？温度曲线的最低点出现在什么时候？请区分地图路线、人数带宽和温度曲线三类信息。

### 7. 论文首页信息抽取

请根据 `paper/attention-is-all-you-need-page1.png` 提取标题、第一作者、作者单位、发布日期和摘要第一句，并输出为 Markdown 表格。看不清的字段请保留原位置并标注“无法辨认”，不要猜测。

### 8. 日常生活：小票核对

请读取购物小票图片，提取商品名称、数量和单价，计算商品金额之和，并与小票总额核对。如果存在优惠、税费或四舍五入，请单独列出并解释差异。

## 三、宣传优先级建议

1. **论文首页转 Markdown**：最容易展示“看图—识别结构—生成可编辑内容”的完整链路，适合科研用户和开发者。
2. **科研图表阅读**：画面直观，回答可以快速验证，适合短视频或产品演示。
3. **小票核对**：普通用户一眼能理解，能体现图片识别和计算结合，适合作为生活场景入口。
4. **拿破仑行军路线图**：故事性强、图表信息密度高，适合展示复杂信息理解，但需要在画面上标注问题区域。

论文首页案例建议选用公开可访问的 arXiv 论文，截取第一页作为图片输入，再让模型输出 Markdown；这样可以同时展示来源、结构化提取和不确定内容处理。
