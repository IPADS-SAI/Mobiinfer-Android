# 面向高通 Hexagon 的全静态量化：Quant.npu

本文整理论文 **Quant.npu: Enabling Efficient Mobile NPU Inference for on-device LLMs via Fully Static Quantization**（arXiv:2605.20295v1，Preprint，2026-05）的方法与结论，并给出对本项目的借鉴点。

- 论文：https://arxiv.org/abs/2605.20295
- 硬件：Qualcomm Hexagon NPU（主测 **SM8650 = 8 Gen 3**，另附 **SM8750 = 8 Elite** 的内存/能耗剖析）
- 模型：LLaMA-3.2-3B-Instruct（主）、Qwen2.5-3B、SmolLM2-1.7B、Qwen3-1.7B、LLaMA3-8B
- 定位：**integer-only 全静态量化**（权重量化之外的另一根轴，与 LES/DSpark 正交）

---

## 1. 背景：Hexagon NPU 的三条硬约束

论文开篇即点名 Qualcomm Hexagon：**matrix units**（高吞吐 GEMM）、**vector units**（element-wise）、**DMA 引擎**。相比移动 GPU 有 >10× 性能、4× 能效，但带来三条架构约束：

1. **偏好整数运算**：整数矩阵乘的面积/能效优于浮点。
2. **必须静态量化**：动态 min/max 归约开销大——例如对 128 元素 INT8 向量做树归约至少需 7 个向量指令周期，成为瓶颈。
3. **细粒度量化低效**：systolic array 偏好粗粒度；逐块（per-block）量化需频繁 dequant，打断流水。**在 Hexagon 上 W4A8 per-tensor 比 W4A16 per-block 快约 20%。**

**问题**：主流 PTQ（QuaRot、SpinQuant 等）面向 GPU / 动态量化；用动态量化模拟去优化，再转成 NPU 需要的**静态**部署时，会因静态量化参数估计不准而**精度崩溃**（例：SmolLM2-1.7B-Instruct 掉 **15.61%**）。

---

## 2. 动机（三个实验发现）

1. **静态参数与旋转矩阵强耦合**：动态激活 scale 在优化中剧烈波动（如第 21 层 Wo 方差 0.58），用动态模拟无法反映静态误差；反之若**优化前就固定**量化参数，则收敛受阻（loss 方差 0.3）——因为最优量化范围会随旋转矩阵优化而漂移。→ **静态标定前置不可行**。
2. **初始化决定收敛**：初始化不当会显著减慢收敛（final loss 方差 0.8）甚至发散。
3. **不是学得越多越好**：联合优化「输入激活 + 输出激活 + 权重 + KV」精度**最差**；排除输出激活变好；**只学 linear 的输入激活 + 权重**最好。
4. **旋转的延迟-精度权衡**：离线融合的旋转（R1、R2）零延迟；在线旋转（R3、R4）需 FP 矩阵乘，约 2× 开销。去掉在线旋转会让 down_proj 输入激活出现严重离群。

---

## 3. 方法：三个技术

### 3.1 Rotation-and-bit-width-aware 初始化

- 旋转后的激活近似**高斯**；未旋转的激活是**重尾**。
- Max-Min 覆盖宽动态范围但密集区粒度粗；Mean-based 中心精度高、裁掉离群。
- **规则**：
  - **旋转激活**（Wq/Wo/Wup 的输入）→ **Mean-based** 初始化（支持更低比特）；
  - **未旋转激活** → **Max-Min** 初始化 + 高比特（8/16-bit），以容纳宽范围。

### 3.2 Distribution-aware Selective Optimization（两阶段）

把量化参数分两类：**旋转分布**（linear 的输入激活与权重，平滑近高斯、可稳定更新）与**非旋转分布**（linear 输出激活、KV，重尾、敏感、难优化）。

- **Stage 1 · 梯度优化**：联合优化 linear 的**输入激活 + 权重**量化参数与**旋转矩阵**。
  - STE 近似取整梯度；梯度缩放 `g = 1/√(N · Qmax)`（`N` 为共享同一量化参数的元素数）以避免量化参数梯度远大于旋转矩阵梯度；
  - 前 128 步加**局部量化误差损失** `min_{s,zp} ‖DQ(Q(x)) − x‖²` 稳定早期收敛；
  - lm_head 的输入/输出激活与权重此阶段**保持浮点**。
- **Stage 2 · 静态标定**：对其余张量（linear 输出激活、KV、SiLU 等）**直接静态标定**，不再优化——因为这些本来就要 8-bit+，表示力足够，继续优化只增复杂度与不稳定。

### 3.3 Adaptive Mixed-Precision

- **去掉在线旋转 R3/R4**（避免 FP 矩阵乘 ~2× 开销），只保留**离线融合进权重的 R1/R2**（零推理开销）。
- 代价：down_proj 输入激活离群严重，8-bit 也掉分。
- **敏感度指标** = 相对量化误差 `ratio = (1/N) Σ |dequant_i − orig_i| / (|orig_i| + 1e-8)`，据此把**少数高敏感 down_proj 激活从 8-bit 提到 16-bit**。
- 实测：**只提升 10%（28 层中 3 层）**即可几乎追回全 16-bit 精度。

### 3.4 量化配置

- 权重 **per-channel 对称**；激活 **per-tensor 对称**（都是为了贴合 NPU）。
- KV cache、linear 输出激活固定 **8-bit**；SiLU 等其余算子固定 **16-bit**；down_proj 激活 **8/16 自适应**。
- 标定：仅 16 条 WikiText-2 样本。
- 训练：4×A40，WikiText-2（bf16, seq 2048）512 步（7 epoch），bs 2 + 2 grad accum；SGD + cosine，旋转 lr 0.1、量化参数 lr 0.01。

## 4. 结果

### 精度（Llama-3.2-3B-Instruct，C4 PPL + 6 个 zero-shot）

| 设置 | 结果 |
|---|---|
| **W8A8** | zero-shot 与 FP32 相当甚至略好 |
| **W4A8** | PPL **28.78 → 19.16**，zero-shot **46.23% → 58.27%（+12.04pp）** |
| **W4A4** | baseline 几乎全崩时仍只掉 ~6%（vs FP32） |

baseline：ExecuTorch、QuaRot（固定 Hadamard）、SpinQuant（只学旋转）；Quant.npu 联合优化旋转 + 静态量化参数。

### 延迟（SM8650，HellaSwag / Persona-Chat / DroidTask）

- Quant.npu-W4A8 比 ExecuTorch-W4A16 **快最高 15.1%**，精度只掉约 1%（全任务平均掉 2.58%、PPL +1.23）。

### 消融（Llama-3.2-3B）

| 配置 | PPL(C4) ↓ | Avg ↑ |
|---|---:|---:|
| FP32 | 22.64 | 0.4939 |
| 纯静态联合优化（baseline） | 69.65 | 0.2969 |
| + 初始化（3.1） | 36.42 | 0.3796 |
| + 选择性优化（3.2） | 30.89 | 0.4015 |
| + 自适应混合精度 10%（3.3） | **22.09** | **0.4733** |
| 全 16-bit（参考） | 21.56 | 0.4785 |
| 仅高精度（无前两项） | 31.16 | 0.3973 |

结论：三技术逐项都有贡献；**10% 高精度** 即可逼近 FP32 / 全 16-bit。

## 5. 对本项目的借鉴点

> 本项目当前是 **Q3_K/Q4_K 专家权重**（权重侧）+ Q8_0 草稿；**激活**多半仍是较高精度。Quant.npu 是"把 HTP 端 GEMM 吃满"的**激活量化/静态化**配套。

1. **坚持粗粒度、静态**：Hexagon 上 **W4A8 per-tensor 比 W4A16 per-block 快 ~20%**。与本项目"专家连续重排 + 简单布局"方向一致；若要上 INT8 激活，应走 **per-tensor 激活 + per-channel 权重**。
2. **只保留离线融合旋转（R1/R2）**：零推理开销；去掉在线旋转（R3/R4）以免 FP 矩阵乘翻倍。
3. **敏感度指导的混合精度**：用**相对量化误差**指标，只把 ~10% 高敏感 down_proj 激活提到 16-bit 即可。这与本项目 LES 的**逐层混合精度量化**是同一思路，可换用更细的敏感度度量来分配比特。
4. **两阶段优化 + 针对性初始化**：是"全静态训练不崩"的关键（若采用带训练的对齐流程）。
5. **正交性提醒**：这是**量化**，不是专家卸载，与 LES/DSpark **正交**；它可与 MoE 卸载叠加（专家权重按后端打包 + 激活全静态），前提是 HTP 侧有对应的 W4A8/INT8 激活 GEMM 内核。

## 6. 相关工作对照

- **QuaRot**：固定 Hadamard 旋转 PTQ。
- **SpinQuant**：只学旋转矩阵（动态量化优化）。
- **ExecuTorch**：边缘运行时，支持 Hexagon NPU 的 per-block 权重 PTQ（W4A16）。
- **MobileQuant**：论文另做对比。
- 概念同族：SmoothQuant（通道级离群抑制）等。
